# Formatka

Formatka – program do projektowania szaf, kuchni i mebli z płyt (Windows).

**Pobieranie:** otwórz [najnowsze wydanie](https://github.com/piotr96muszynski-collab/formatka-wydania/releases/latest) i pobierz plik `Formatka-...-setup.exe`. Po instalacji program sam sprawdza i pobiera nowe wersje.

To repozytorium zawiera tylko pliki do pobrania.
