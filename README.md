# Formatka

Formatka – program do projektowania szaf, kuchni i mebli z płyt (Windows).

## Pobieranie

**[Pobierz instalator Formatka 0.99.37](https://github.com/piotr96muszynski-collab/formatka-wydania/releases/download/v0.99.37/Formatka-0.99.37-setup.exe)**, uruchom go i gotowe. Po instalacji program sam sprawdza i pobiera nowe wersje – instalator pobierasz tylko raz.

Przy pierwszym uruchomieniu Windows może pokazać okno *System Windows ochronił ten komputer* – kliknij **Więcej informacji** → **Uruchom mimo to**.

To repozytorium zawiera tylko pliki do pobrania.
